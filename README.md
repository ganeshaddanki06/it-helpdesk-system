# 🖥️ ACET IT Helpdesk & Asset Management System

An enterprise-grade, full-stack IT support ticketing and hardware asset management system designed for academic institutions and modern offices. It streamlines campus infrastructure maintenance, tracks hardware lifecycles, and automates compliance reporting for accreditations like NAAC and NBA.

## 🚀 Key Features

* **Relational Hardware Inventory:** Tracks campus workstations (Dell OptiPlex), switches, and projectors with unique institutional asset tags and state machine lifecycles (Operational ➔ Under Maintenance ➔ Decommissioned).
* **Automated IT Support Ticketing:** Complete ticket lifecycle management (`Open` ➔ `In Progress` ➔ `Resolved` ➔ `Closed`) linked directly to physical hardware tags.
* **Dynamic Email Notifications:** Integrated Gmail SMTP service with secure App Password authentication for automated instant email alerts on ticket updates.
* **Institutional Audit Readiness:** Generates transparent digital audit trails and compliance reports for lab uptime and maintenance history.
* **Secure Authentication:** Role-based access control and secure API endpoints.
